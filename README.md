# Hardware Engineering — Year 1

This repository tracks my first year of learning hardware engineering and the projects I build along the way.

## Roadmap

```text
[M1-M4] Nand2Tetris ──> [M5-M6] Electronics ──> [M7-M8] Robotics & CAD ──> [M9-M10] FRC & PCBs ──> [M11-M12] Diagnostics & IT
```

### Months 1–4 — Nand2Tetris
Logic gates → CPU → Assembly → VM → Compiler → OS

### Months 5–6 — Electronics
Circuits, Arduino, sensors, GPIO, PWM, UART, I²C, SPI

### Months 7–8 — Robotics & CAD
Motors, Raspberry Pi, Linux, communication, CAD

### Months 9–10 — FRC & PCB Design
Power systems, motor controllers, KiCad, custom PCBs, WPILib

### Months 11–12 — Diagnostics & IT
Troubleshooting, soldering, repair, Linux networking, PXE

## Projects

## Engineering Standard

For each project:

```text
Design ──> Build ──> Test ──> Debug ──> Fix ──> Document
```

## End Goal

By the end of the year, I want to be comfortable going from digital logic all the way to physical hardware and being able to figure out how an unfamiliar system works.
